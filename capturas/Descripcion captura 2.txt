15. Funcionalidad que transmite la interfaz

Esta pantalla representa un módulo de reporte de rendimiento académico por curso. El flujo de uso es el siguiente:

El usuario selecciona un curso desde un listado desplegable (en este caso, C0001 - Base de Datos II).
Al pulsar Consultar, el sistema muestra una alerta confirmando el curso seleccionado.
Se presenta un resumen estadístico del curso con información como el profesor responsable, el número de alumnos matriculados, el promedio general del curso y el conteo de aprobados y desaprobados.
Debajo se muestra un detalle por alumno, incluyendo las dos notas parciales, la nota del examen, el promedio calculado mediante la fórmula (Nota1 + Nota2 + Examen) / 3 y el estado final (Aprobado o Desaprobado).
Los valores y estados se destacan visualmente mediante colores (verde para aprobados y rojo para desaprobados), facilitando una interpretación rápida del rendimiento académico. Finalmente, un botón Volver permite regresar a la pantalla anterior.
