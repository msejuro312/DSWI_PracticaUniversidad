1. Script SQL — BDUNIVERSIDAD2026 + Stored Procedures

Script_SQL_BDUNIVERSIDAD2026_ok.sql

Script que crea la base de datos BDUNIVERSIDAD2026 con 5 tablas y stored procedures para cada consulta del proyecto.

Estructura de tablas

TablaTipoColumnas clave
AlumnoMaestracodalu CHAR(5) PK, nomalu VARCHAR(60), carrera, semestre, estado
ProfesorMaestracodprof CHAR(5) PK, nomprof VARCHAR(60), especialidad, grado, estado
CursoMaestracodcurso CHAR(5) PK, nomcurso VARCHAR(60), creditos, codprof FK → Profesor, estado
MatriculaTransaccionalidmatricula INT PK, codalu FK → Alumno, codcurso FK → Curso, periodo VARCHAR(10)
NotasTransaccionalidnota INT PK, idmatricula FK → Matricula, nota1 DECIMAL(5,2), nota2 DECIMAL(5,2), examen DECIMAL(5,2)

Stored Procedures

ProcedimientoParametrosProposito
sp_list_cursos(ninguno)Lista CodCurso + NomCurso para dropdown
sp_list_periodos(ninguno)Lista periodos distintos desde Matricula para dropdown
NotasPeriodo@periodo VARCHAR(10)Notas por periodo con JOIN a Alumno, Curso, Profesor. Calcula promedio = (Nota1+Nota2+Examen)/3
ReporteRendimientoCurso@codCurso CHAR(5)Detalle de alumnos por curso con promedio y estado (Aprobado si >= 10.5)
ResumenRendimientoCurso@codCurso CHAR(5)Resumen por curso: cant alumnos, promedio general, aprobados (>=11), desaprobados (<11)
Conceptos clave del script SQL:
  • CREATE DATABASE / USE — Crear y seleccionar BD
  • CREATE TABLE con tipos: INT, VARCHAR(n), DECIMAL(5,2), CHAR(5)
  • PRIMARY KEY y REFERENCES (FK)
  • INSERT INTO ... VALUES para carga masiva de datos de prueba
  • CREATE OR ALTER PROCEDURE — Crea o reemplaza un SP
  • IIF(condicion, valor_si, valor_no) — Funcion condicional en SQL Server
  • El promedio se calcula en el SP con (nota1 + nota2 + examen) / 3.0
-- Fragmento ilustrativo: SP de resumen
CREATE OR ALTER PROCEDURE ResumenRendimientoCurso
    @codCurso CHAR(5)
AS
BEGIN
    SELECT
        c.codcurso, c.nomcurso, p.nomprof,
        COUNT(DISTINCT m.codalu) AS cantAlumnos,
        ROUND(AVG((n.nota1 + n.nota2 + n.examen) / 3.0), 2) AS promGeneral,
        SUM(IIF((n.nota1 + n.nota2 + n.examen) / 3.0 >= 11, 1, 0)) AS aprobados,
        SUM(IIF((n.nota1 + n.nota2 + n.examen) / 3.0 < 11, 1, 0)) AS desaprobados
    FROM Notas n
    INNER JOIN Matricula m ON n.idmatricula = m.idmatricula
    INNER JOIN Curso c ON m.codcurso = c.codcurso
    INNER JOIN Profesor p ON c.codprof = p.codprof
    WHERE m.codcurso = @codCurso
    GROUP BY c.codcurso, c.nomcurso, p.nomprof
END
Nota: El SP ReporteRendimientoCurso usa umbral >= 10.5, mientras que ResumenRendimientoCurso usa >= 11. Esto puede unificarse si se desea.

4. Program.cs — Punto de entrada

Program.cs

Configura los servicios de la aplicacion, el pipeline HTTP y arranca el servidor web.

var builder = WebApplication.CreateBuilder(args);

// Registrar servicios en el contenedor DI
builder.Services.AddControllersWithViews();

var app = builder.Build();

// Middleware pipeline
if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/Home/Error");
    app.UseHsts();
}

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();
app.UseAuthorization();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}"
);

app.Run();
Explicacion linea por linea:
LineaQue hace
builder.Services.AddControllersWithViews()Registra servicios MVC (controladores + vistas).
UseExceptionHandler("/Home/Error")Redirige a la pagina de error en produccion.
UseHsts()HTTP Strict Transport Security (solo produccion).
UseHttpsRedirection()Redirige HTTP a HTTPS.
UseStaticFiles()Sirve archivos estaticos de wwwroot (CSS, JS).
UseRouting()Activa el enrutamiento.
UseAuthorization()Middleware de autorizacion.
MapControllerRoute(...)Ruta por defecto: {controller=Home}/{action=Index}/{id?}. Home/Index es la pagina principal.
Importante: Este proyecto NO usa Entity Framework. La conexion a BD se hace con ADO.NET puro (Microsoft.Data.SqlClient) llamando a stored procedures directamente en los controladores.

6. Controladores

Los controladores reciben peticiones HTTP, ejecutan logica (consultan BD mediante stored procedures) y devuelven vistas con datos.

Patron comun en los controladores de negocio:

  • Reciben IConfiguration por inyeccion de dependencias en el constructor
  • Obtienen la cadena de conexion con configuration.GetConnectionString("conexion")
  • Definen metodos privados que encapsulan llamadas a SP con ADO.NET
  • Usan SqlConnection, SqlCommand con CommandType.StoredProcedure
  • Parametros con AddWithValue (previene inyeccion SQL)
  • Mapean manualmente SqlDataReader a modelos C# usando indices de columna
  • Usan ViewBag para datos auxiliares (dropdowns, mensajes, paginacion)
  • Usan await Task.Run(() => ...) para las operaciones ADO.NET (pseudo-asincrono)

6.2 NotasController.cs

Controllers\NotasController.cs

Controlador para la consulta de notas filtradas por periodo academico con paginacion en memoria.

namespace WebApplication2.Controllers;

public class NotasController : Controller
{
    private readonly string? conexion;

    public NotasController(IConfiguration configuration)
    {
        conexion = configuration.GetConnectionString("conexion");
    }

    // Metodo privado: llama al SP NotasPeriodo y devuelve List<NotasPeriodo>
    List<NotasPeriodo> ListarNotasPeriodo(string periodo) { ... }

    // Metodo privado: llama al SP sp_list_periodos y devuelve List<string>
    List<string> listPeriodos() { ... }

    public async Task<IActionResult> Index(string periodo = "", int page = 0)
    {
        List<string> periodos = listPeriodos();
        ViewBag.periodos = new SelectList(periodos);

        IEnumerable<NotasPeriodo> notas = ListarNotasPeriodo(periodo);
        int filas = 10;
        int totalRegistros = notas.Count();
        int totalPaginas = totalRegistros % filas == 0 ?
                            (totalRegistros / filas) : (totalRegistros / filas + 1);

        ViewBag.totalRegistros = totalRegistros;
        ViewBag.totalPaginas = totalPaginas;
        ViewBag.page = page;
        ViewBag.periodo = periodo;

        return View(await Task.Run(() => notas.Skip(filas * (page - 1)).Take(filas)));
    }
}
Conceptos nuevos (vs. HomeController):
ConceptoExplicacion
IConfigurationInterfaz para leer configuraciones (appsettings.json). Se inyecta por constructor.
GetConnectionString("conexion")Recupera la cadena de conexion desde appsettings.json
SqlConnectionClase de ADO.NET para conectar a SQL Server. Se usa dentro de using.
SqlCommandEjecuta comandos SQL. Se asigna el SP con CommandType.StoredProcedure.
AddWithValueAgrega parametros nominativos (ej. @periodo) previniendo inyeccion SQL.
ExecuteReader()Ejecuta SELECT y devuelve un SqlDataReader para leer filas una por una.
ViewBagObjeto dinamico para pasar datos del controlador a la vista SIN usar el modelo fuerte.
SelectListHelper para poblar un <select> desde una lista de datos.
.Skip().Take()Paginacion en memoria (LINQ): se traen TODOS los registros del SP y se filtra por pagina.
await Task.Run()Ejecuta el codigo sincrono en un thread del pool (pseudo-asincrono).
Observacion: La paginacion se hace en memoria (LINQ .Skip().Take()) y no en SQL. Esto significa que el SP devuelve TODAS las filas y luego C# selecciona solo las de la pagina actual. Para grandes volumenes de datos seria mas eficiente usar OFFSET/FETCH en el propio SP.

6.3 RendimientoController.cs

Controllers\RendimientoController.cs

Reporte de rendimiento academico filtrado por curso. Incluye resumen estadistico y detalle de alumnos.

namespace WebApplication2.Controllers;

public class RendimientoController : Controller
{
    private readonly string? conexion;

    public RendimientoController(IConfiguration configuration)
    {
        conexion = configuration.GetConnectionString("conexion");
    }

    // Metodo privado: lista cursos para dropdown
    List<Curso> listCursos() { ... }  // SP: sp_list_cursos

    // Metodo privado: detalle de alumnos por curso
    List<ReporteRendimiento> ListarReporte(string codCurso) { ... }  // SP: ReporteRendimientoCurso

    // Metodo privado: resumen estadistico del curso
    List<ResumenCurso> ListarResumen(string codCurso) { ... }  // SP: ResumenRendimientoCurso

    public async Task<IActionResult> Index(string codCurso = "")
    {
        List<Curso> cursos = listCursos();
        ViewBag.cursos = new SelectList(cursos, "CodCurso", "NomCurso");

        if (!string.IsNullOrEmpty(codCurso))
        {
            try
            {
                List<ReporteRendimiento> reporte = ListarReporte(codCurso);
                List<ResumenCurso> resumen = ListarResumen(codCurso);
                ViewBag.resumen = resumen.FirstOrDefault();
                ViewBag.totalRegistros = reporte.Count;
                return View(await Task.Run(() => reporte));
            }
            catch (Exception ex)
            {
                ViewBag.Error = ex.Message;
                ViewBag.totalRegistros = 0;
                return View(new List<ReporteRendimiento>());
            }
        }

        ViewBag.totalRegistros = 0;
        return View(new List<ReporteRendimiento>());
    }
}
Diferencias con NotasController:
  • Llama a dos SP diferentes: ReporteRendimientoCurso (detalle) y ResumenRendimientoCurso (resumen)
  • Usa try/catch para manejar errores (si el curso no existe, el SP lanza excepcion)
  • No tiene paginacion (todas las filas en una sola pagina)
  • Pasa el resumen via ViewBag.resumen (un solo objeto, no una lista)
Patron de los metodos privados con ADO.NET: 
List<T> Metodo(string parametro)
{
    List<T> temporal = new List<T>();
    using (SqlConnection con = new SqlConnection(conexion))
    {
        SqlCommand command = new SqlCommand("NombreDelSP", con);
        command.CommandType = CommandType.StoredProcedure;
        command.Parameters.AddWithValue("@param", parametro);
        con.Open();
        using (SqlDataReader reader = command.ExecuteReader())
        {
            while (reader.Read())
            {
                T item = new T
                {
                    Prop1 = reader.GetTipo(0),  // por indice de columna
                    Prop2 = reader.GetTipo(1)
                };
                temporal.Add(item);
            }
        }
    }
    return temporal;
}

    <p>No se encontraron registros para el curso seleccionado.</p>
}
Novedades en esta vista (vs. Notas):
  • Renderiza dos tablas: resumen estadistico + detalle de alumnos
  • El resumen se obtiene de ViewBag.resumen (objeto ResumenCurso)
  • El estado se colorea: text-success fw-bold (verde) si aprobado, text-danger fw-bold (rojo) si desaprobado
  • Manejo de errores con ViewBag.Error en un alert rojo

9. Resumen — Pasos para recrear el proyecto desde cero

  1. Crear la BD: Ejecutar Script_SQL_BDUNIVERSIDAD2026_ok.sql en SQL Server Management Studio (SSMS). Esto crea la BD, las tablas, datos de prueba y los 5 stored procedures.
  2. Crear proyecto: dotnet new mvc -n WebApplication2 o desde Visual Studio con plantilla ASP.NET Core MVC (.NET 7).
  3. Agregar paquete NuGet: dotnet add package Microsoft.Data.SqlClient --version 5.2.0
  4. Configurar cadena de conexion: En appsettings.json, agregar ConnectionStrings.conexion con autenticacion SQL (sa) apuntando a BDUNIVERSIDAD2026.
  5. Crear Models (en Models/):
    • NotasPeriodo.cs — CodAlu, NomAlu, NomCurso, NomProf, Nota1, Nota2, Examen, Promedio
    • Curso.cs — CodCurso, NomCurso (para dropdown)
    • ReporteRendimiento.cs — CodAlu, NomAlu, Nota1, Nota2, Examen, Promedio, Estado
    • ResumenCurso.cs — CodCurso, NomCurso, NomProf, CantAlumnos, PromGeneral, Aprobados, Desaprobados
    • Conservar ErrorViewModel.cs de la plantilla
  6. Crear Controllers (en Controllers/):
    • HomeController — Index, Privacy, Error (de la plantilla)
    • NotasController — Index con filtro por periodo, paginacion en memoria (LINQ Skip/Take)
    • RendimientoController — Index con filtro por curso, dos SP (detalle + resumen), manejo de errores
  7. Crear Views (en Views/): Adaptar Layout con navbar a Home/Notas/Rendimiento/Privacidad, crear las vistas Index de cada controlador con tablas Bootstrap.
  8. Ejecutar el SP de resumen en BD antes de probar: ejecutar ResumenRendimientoCurso desde SSMS para crearlo.
  9. Ejecutar: dotnet run y probar en http://localhost:5254.
