1. Script SQL — BDUNIVERSIDAD2026

Script_SQL_BDUNIVERSIDAD2026_ok.sql

Script que crea la base de datos BDUNIVERSIDAD2026 con 6 tablas maestras y 1 tabla transaccional (Matricula). Contiene INSERT masivos con datos de prueba.

Estructura de tablas

TablaTipoProposito
ALUMaestraAlumnos (CodAlu, NomAlu, ApeAlu, Email, FecNac, etc.)
CURMaestraCursos (CodCur, NomCur, Cred, Horas)
PROMaestraProfesores (CodPro, NomPro, ApePro, Email, Especialidad)
PERMaestraPeriodos academicos (CodPer, NomPer, FecIni, FecFin)
PREREQMaestraPrerequisitos (CodCurso, CodPreReq)
MATTransaccionalMatricula (Id, CodAlu, CodCur, CodPro, CodPer, Nota1, Nota2, Examen, Promedio)
Conceptos clave:
  • CREATE DATABASE / USE — Crear y seleccionar BD
  • CREATE TABLE con tipos: INT, VARCHAR(n), DECIMAL(18,2), DATE, CHAR(n)
  • PRIMARY KEY y REFERENCES (FK)
  • INSERT INTO ... VALUES para carga de datos
  • UPDATE Matricula SET Promedio = Nota1*0.25 + Nota2*0.25 + Examen*0.50 — Formula de promedio ponderado
-- Fragmento ilustrativo
CREATE TABLE ALU (
    CodAlu    INT NOT NULL,
    NomAlu    VARCHAR(80),
    ApeAlu    VARCHAR(80),
    Email     VARCHAR(100),
    FecNac    DATE,
    PRIMARY KEY (CodAlu)
);

CREATE TABLE MAT (
    Id        INT IDENTITY(1,1),
    CodAlu    INT REFERENCES ALU(CodAlu),
    CodCur    CHAR(3) REFERENCES CUR(CodCur),
    CodPro    INT REFERENCES PRO(CodPro),
    CodPer    CHAR(4) REFERENCES PER(CodPer),
    Nota1     DECIMAL(18,2),
    Nota2     DECIMAL(18,2),
    Examen    DECIMAL(18,2),
    Promedio  DECIMAL(18,2),
    PRIMARY KEY (Id)
);
Dato importante: El campo Promedio se calcula con UPDATE MAT SET Promedio = Nota1*0.25 + Nota2*0.25 + Examen*0.50. La formula da peso de 25% a cada nota parcial y 50% al examen final.
Queries usados en la app:
  • Notas por periodo: SELECT MAT.*, ALU.NomAlu, CUR.NomCur, PRO.NomPro FROM MAT JOIN ALU ON ... JOIN CUR ON ... JOIN PRO ON ... WHERE CodPer = @p
  • Rendimiento por curso: Similar pero filtrando por CodCur y calculando estado segun Promedio
  • Cursos: SELECT CodCur, NomCur FROM CUR para llenar dropdown
  • Periodos: SELECT CodPer, NomPer FROM PER para llenar dropdown

2. WebApplication2.csproj — Archivo de proyecto

WebApplication2.csproj

Define el SDK, framework, paquetes NuGet y configuracion del proyecto ASP.NET Core.

<Project Sdk="Microsoft.NET.Sdk.Web">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="Microsoft.Data.SqlClient" Version="5.2.2" />
  </ItemGroup>
</Project>
Explicacion:
  • Sdk="Microsoft.NET.Sdk.Web" — SDK especifico para apps web ASP.NET Core
  • net8.0 — Framework .NET 8 (LTS vigente)
  • Nullable enable — Habilita tipos anulables (string? etc.)
  • ImplicitUsings enable — Importa automaticamente System, System.Collections.Generic, System.Linq, System.Threading.Tasks, Microsoft.AspNetCore.Mvc, etc.
  • Microsoft.Data.SqlClient 5.2.2 — Driver ADO.NET para SQL Server (no usa Entity Framework)

4. Program.cs — Punto de entrada

Program.cs

Configura los servicios de la aplicacion, el pipeline HTTP y arranca el servidor web.

var builder = WebApplication.CreateBuilder(args);

// Registrar servicios en el contenedor DI
builder.Services.AddControllersWithViews();

var app = builder.Build();

// Middleware pipeline
if (!app.Environment.IsDevelopment())
{
    app.UseExceptionHandler("/Home/Error");
    app.UseHsts();
}

app.UseHttpsRedirection();
app.UseStaticFiles();
app.UseRouting();
app.UseAuthorization();

app.MapControllerRoute(
    name: "default",
    pattern: "{controller=Home}/{action=Index}/{id?}"
);

app.Run();
Explicacion linea por linea:
LineaQue hace
builder.Services.AddControllersWithViews()Registra servicios MVC (controladores + vistas). Equivale a AddMvc() pero mas ligero.
UseExceptionHandler("/Home/Error")Redirige a la pagina de error en produccion.
UseHsts()HTTP Strict Transport Security (solo desarrollo).
UseHttpsRedirection()Redirige HTTP a HTTPS.
UseStaticFiles()Sirve archivos estaticos de wwwroot (CSS, JS, imagenes).
UseRouting()Activa el enrutamiento.
UseAuthorization()Middleware de autorizacion.
MapControllerRoute(...)Ruta por defecto: {controller=Home}/{action=Index}/{id?}
Importante: Este proyecto NO usa Entity Framework. La conexion a BD se hace con ADO.NET puro (Microsoft.Data.SqlClient) directamente en los controladores. Cada controlador crea su propia conexion con new SqlConnection(...).

6.2 NotasController.cs

Controllers\NotasController.cs

Controlador mas importante del T1. Consulta notas filtradas por periodo academico con paginacion.

namespace WebApplication2.Controllers;

public class NotasController : Controller
{
    private readonly IConfiguration _configuration;

    public NotasController(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    public IActionResult Index(string? periodo, int page = 1)
    {
        string connectionString = _configuration.GetConnectionString("DefaultConnection");
        int filasPagina = 8;

        using (SqlConnection cn = new SqlConnection(connectionString))
        {
            cn.Open();

            // 1. Cargar periodos en ViewBag
            SqlCommand cmdPer = new SqlCommand("SELECT CodPer, NomPer FROM PER", cn);
            SqlDataReader drPer = cmdPer.ExecuteReader();
            ViewBag.periodos = new SelectList( ... );
            drPer.Close();

            if (!string.IsNullOrEmpty(periodo))
            {
                // 2. Contar total registros
                SqlCommand cmdCount = new SqlCommand("SELECT COUNT(*) FROM MAT WHERE CodPer = @p", cn);
                cmdCount.Parameters.AddWithValue("@p", periodo);
                int totalRegistros = (int)cmdCount.ExecuteScalar();
                ViewBag.totalRegistros = totalRegistros;
                ViewBag.totalPaginas = (int)Math.Ceiling((double)totalRegistros / filasPagina);
                ViewBag.page = page;
                ViewBag.periodo = periodo;

                // 3. Consultar con paginacion (OFFSET / FETCH NEXT)
                SqlCommand cmd = new SqlCommand(@"SELECT M.Id, M.CodAlu, A.NomAlu,
                    C.NomCur, P.NomPro, M.Nota1, M.Nota2, M.Examen, M.Promedio
                    FROM MAT M JOIN ALU A ON M.CodAlu = A.CodAlu
                    JOIN CUR C ON M.CodCur = C.CodCur
                    JOIN PRO P ON M.CodPro = P.CodPro
                    WHERE M.CodPer = @p
                    ORDER BY M.Id
                    OFFSET @offset ROWS FETCH NEXT @limit ROWS ONLY", cn);
                cmd.Parameters.AddWithValue("@p", periodo);
                cmd.Parameters.AddWithValue("@offset", (page - 1) * filasPagina);
                cmd.Parameters.AddWithValue("@limit", filasPagina);

                SqlDataReader dr = cmd.ExecuteReader();
                List<NotasPeriodo> lista = new List<NotasPeriodo>();
                while (dr.Read())
                {
                    lista.Add(new NotasPeriodo { ... });
                }
                return View(lista);
            }
        }
        return View(new List<NotasPeriodo>());
    }
}
Conceptos nuevos (vs. HomeController):
ConceptoExplicacion
IConfigurationInterfaz para leer configuraciones (appsettings.json). Se inyecta por constructor.
GetConnectionString("DefaultConnection")Recupera la cadena de conexion desde appsettings.json
SqlConnectionClase de ADO.NET para conectar a SQL Server.
SqlCommandEjecuta comandos SQL con parametros (AddWithValue)
ExecuteReader()Ejecuta SELECT y devuelve un SqlDataReader para leer filas.
ExecuteScalar()Ejecuta SELECT y devuelve la primera columna de la primera fila (COUNT, SUM, etc.).
OFFSET / FETCH NEXTPaginacion a nivel SQL (mas eficiente que cargar todo en memoria).
ViewBagObjeto dinamico para pasar datos del controlador a la vista SIN usar el modelo fuerte (@model).
SelectListHelper para poblar <select> desde una lista de datos.
Math.Ceiling()Redondea hacia arriba para calcular total de paginas.
Parametros con AddWithValue: Se usa @p, @offset, @limit como parametros nominativos. Esto previene inyeccion SQL.

6.3 RendimientoController.cs

Controllers\RendimientoController.cs

Reporte de rendimiento academico filtrado por curso. Incluye calculo de estado (Aprobado/Desaprobado) en memoria.

namespace WebApplication2.Controllers;

public class RendimientoController : Controller
{
    private readonly IConfiguration _configuration;

    public RendimientoController(IConfiguration configuration)
    {
        _configuration = configuration;
    }

    public IActionResult Index(string? codCurso)
    {
        string connectionString = _configuration.GetConnectionString("DefaultConnection");

        using (SqlConnection cn = new SqlConnection(connectionString))
        {
            cn.Open();

            // Cargar cursos para el dropdown
            SqlCommand cmdCur = new SqlCommand("SELECT CodCur, NomCur FROM CUR", cn);
            SqlDataReader drCur = cmdCur.ExecuteReader();
            ViewBag.cursos = new SelectList( ... );
            drCur.Close();

            if (!string.IsNullOrEmpty(codCurso))
            {
                // Validar que el curso exista
                SqlCommand cmdVal = new SqlCommand("SELECT COUNT(*) FROM CUR WHERE CodCur = @c", cn);
                cmdVal.Parameters.AddWithValue("@c", codCurso);
                int existe = (int)cmdVal.ExecuteScalar();

                if (existe == 0)
                {
                    ViewBag.Error = "El codigo de curso ingresado no existe.";
                    return View(new List<ReporteRendimiento>());
                }

                // Consultar notas del curso
                SqlCommand cmd = new SqlCommand(@"SELECT M.CodAlu, A.NomAlu, M.Nota1, M.Nota2, M.Examen, M.Promedio
                    FROM MAT M JOIN ALU A ON M.CodAlu = A.CodAlu WHERE M.CodCur = @c", cn);
                cmd.Parameters.AddWithValue("@c", codCurso);

                SqlDataReader dr = cmd.ExecuteReader();
                List<ReporteRendimiento> lista = new List<ReporteRendimiento>();
                while (dr.Read())
                {
                    var item = new ReporteRendimiento { ... };
                    item.Estado = item.Promedio >= 13 ? "Aprobado" : "Desaprobado";
                    lista.Add(item);
                }
                ViewBag.totalRegistros = lista.Count;
                return View(lista);
            }
        }
        return View(new List<ReporteRendimiento>());
    }
}
Diferencias con NotasController:
  • Usa validacion: verifica si el curso existe antes de consultar
  • No tiene paginacion (todas las filas en una sola pagina)
  • Calcula Estado en memoria: Promedio >= 13 ? "Aprobado" : "Desaprobado"
  • Muestra error via ViewBag.Error si el curso no existe
  • ViewBag.totalRegistros se asigna desde lista.Count (ya en memoria)

9. Resumen — Pasos para recrear el proyecto desde cero

  1. Crear la BD: Ejecutar Script_SQL_BDUNIVERSIDAD2026_ok.sql en SQL Server Management Studio (SSMS).
  2. Crear proyecto: dotnet new mvc -n WebApplication2
  3. Agregar paquete NuGet: dotnet add package Microsoft.Data.SqlClient --version 5.2.2
  4. Configurar cadena de conexion: En appsettings.json, agregar ConnectionStrings.DefaultConnection apuntando a BDUNIVERSIDAD2026.
  5. Crear Models: NotasPeriodo.cs, Curso.cs, ReporteRendimiento.cs (y conservar ErrorViewModel.cs de la plantilla).
  6. Crear Controllers:
    • HomeController (Index, Privacy, Error) — generado por plantilla
    • NotasController (Index con filtro por periodo + paginacion)
    • RendimientoController (Index con filtro por curso + estado calculado)
  7. Crear Views: Adaptar Layout con navbar, crear vistas para Home, Notas, Rendimiento y Shared/Error.
  8. Ejecutar: dotnet run y probar en http://localhost:5254.
